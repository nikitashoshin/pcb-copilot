# PCB Copilot

## Инженерный анализ

PCB Copilot дополнительно формирует структурированный предварительный инженерный анализ проекта. Раздел показывает:

- недостающие инженерные параметры;
- причины выбора функциональных блоков;
- инженерные риски и их приоритеты;
- предварительный бюджет питания;
- GPIO / peripheral budget для STM32;
- решения, которые должен принять инженер;
- рекомендуемые следующие шаги.

Инженерный анализ не является финальным инженерным заключением. Он не заменяет расчёты, выбор компонентов, проверку схемы, ERC/DRC, оценку зазоров, теплового режима, EMC/ESD/EFT и обязательную ручную проверку инженером.

## ZIP-export проекта

MVP умеет сформировать ZIP-пакет инженерного черновика проекта. Архив содержит исходные требования `project-spec.json`, BoM в CSV, Markdown-отчёт и папку `kicad` с черновыми заготовками файлов KiCad.

Файлы `.kicad_pro`, `.kicad_sch` и `.kicad_pcb` являются placeholder-заготовками. Они не содержат готовую схему, расстановку компонентов, трассировку или производственно проверенную плату. Перед использованием в реальном проекте инженер должен вручную проверить компоненты, footprint, питание, защиты, зазоры, EMC/ESD/EFT и выполнить полноценную схемотехнику и трассировку.

PCB Copilot - веб-приложение-помощник для инженера-электронщика. Цель проекта - ускорить старт разработки типовой печатной платы для KiCad: сформировать архитектуру, список функциональных блоков, черновую BoM, инженерные предупреждения и в дальнейшем ZIP-архив с черновиком KiCad-проекта.

Проект не является автогенератором полностью готовых плат. Все результаты требуют ручной проверки инженером перед производством или применением.

## Первый MVP-сценарий

Промышленный контроллер:

- STM32;
- питание 24 В DC;
- RS-485;
- 4 дискретных входа 24 В;
- 2 релейных выхода;
- светодиодная индикация;
- SWD для прошивки и отладки;
- размер платы до 80 x 60 мм;
- целевой формат - KiCad.

## План запуска

1. Зафиксировать модель проекта и список функциональных блоков.
2. Добавить минимальный backend API для приема параметров и выдачи JSON-модели.
3. Добавить простой frontend для выбора сценария и просмотра результата.
4. Реализовать генератор черновых KiCad-файлов на основе шаблонов.
5. Добавить экспорт ZIP-архива с KiCad-проектом.
6. Добавить проверки, предупреждения и документацию для инженера.

## Текущий статус

Создана начальная структура MVP и базовая документация. Сложные backend, frontend и KiCad-генератор пока не реализованы.
