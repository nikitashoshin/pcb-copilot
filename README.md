# PCB Copilot

PCB Copilot - веб-приложение-помощник для инженера-электронщика. Цель проекта - ускорить старт разработки типовой печатной платы для KiCad: сформировать архитектуру, список функциональных блоков, черновую BoM, инженерные предупреждения и в дальнейшем ZIP-архив с черновиком KiCad-проекта.

Проект не является автогенератором полностью готовых плат. Все результаты требуют ручной проверки инженером перед производством или применением.

## Первый MVP-сценарий

Промышленный контроллер:

- STM32;
- питание 24 В DC;
- RS-485;
- 4 дискретных входа 24 В;
- 2 релейных выхода;
- светодиодная индикация;
- SWD для прошивки и отладки;
- размер платы до 80 x 60 мм;
- целевой формат - KiCad.

## План запуска

1. Зафиксировать модель проекта и список функциональных блоков.
2. Добавить минимальный backend API для приема параметров и выдачи JSON-модели.
3. Добавить простой frontend для выбора сценария и просмотра результата.
4. Реализовать генератор черновых KiCad-файлов на основе шаблонов.
5. Добавить экспорт ZIP-архива с KiCad-проектом.
6. Добавить проверки, предупреждения и документацию для инженера.

## Текущий статус

Создана начальная структура MVP и базовая документация. Сложные backend, frontend и KiCad-генератор пока не реализованы.
